# Code of conduct

Treat participants respectfully. Discuss technical claims with evidence and make
room for different experience levels. Harassment, discrimination, threats,
publication of private information, impersonation and deliberate security abuse
are unacceptable in project issues, pull requests and discussions.

Maintainers may edit/remove harmful content, close disruptive discussions and
restrict participation proportionately. Enforcement concerns can be raised with
the repository maintainer through GitHub without repeating private information.
Security-sensitive reports should follow SECURITY.md. Decisions should protect
affected participants and explain the relevant rule where privacy permits.
